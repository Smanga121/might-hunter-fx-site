How the EA is designed

01 · ENTRY

BUY and SELL

EMA crossover with RSI confirmation. It checks completed candles rather than repeatedly entering on the same candle.

02 · PROTECTION

Stop and target

ATR-based stop-loss and a take-profit target set at 1.5 times the initial stop distance.

03 · FILTERS

Risk controls

Position sizing from estimated stop-loss cash risk, spread filter, one position at a time, and daily equity-loss lock.

Risk warning

This EA is experimental code, not a verified profitable system. Test and inspect it on a demo account first. Slippage, commissions, spread, broker settings, and gaps can cause losses beyond the intended amount. The daily lock is not a guarantee against loss.

Setup from your Android phone

  1. Download the EA source file using the button above after publishing this folder.
  2. Use a trusted Windows MT5 computer or compatible Windows VPS to open the file in MetaEditor and compile it into an .ex5 file.
  3. Run the compiled EA in Strategy Tester and on an Exness demo account before considering any live trading.
  4. Keep AutoTrading disabled until you understand the settings and have checked the test results.

Android MT5 can monitor trades, but it does not run custom Expert Advisors directly.
